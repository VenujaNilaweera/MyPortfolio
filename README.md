# Venuja Nilaweera — Portfolio

A single-page portfolio site. Plain HTML/CSS, no build step, no dependencies.

## How to put it online with GitHub Pages (free)

1. Go to https://github.com/new and create a repository named **`VenujaNilaweera.github.io`**
   (use your exact GitHub username — this special name gives you the URL `https://venujanilaweera.github.io`).
2. Upload **everything in this folder** — `index.html`, the `images/` folder, and the CV PDF.
   (On the repo page: **Add file → Upload files** → drag them all in → **Commit changes**.)
3. Go to the repo's **Settings → Pages**. Under "Build and deployment", set **Source = Deploy from a branch**,
   **Branch = main**, folder **/(root)**, and **Save**.
4. Wait ~1 minute, then open **https://venujanilaweera.github.io** — your site is live.

You can then put that link in your CV, LinkedIn, and applications.

> Tip: if you'd rather keep the repo named something else (like `portfolio`), that also works —
> the site just lives at `https://venujanilaweera.github.io/portfolio` instead.

## Adding your photos

Drop your project images into the `images/` folder using these exact names, and they appear
automatically (until you add them, a labelled placeholder box shows where each one goes):

| File name                | Shows up in            |
|--------------------------|------------------------|
| `thermalflow-1.jpg`      | ThermalFlow            |
| `thermalflow-2.jpg`      | ThermalFlow            |
| `eggdetect-1.jpg`        | Parasitic Egg Detection|
| `eggdetect-2.jpg`        | Parasitic Egg Detection|
| `asw-1.jpg`              | Active Suspension Wheelchair |
| `asw-2.jpg`              | Active Suspension Wheelchair |
| `autobot-1.jpg`          | AUTOBOT-X              |

`.jpg` or `.png` both work — just match the name (keep the extension consistent with the file).
Landscape photos look best. You can add more slots later; ask me and I'll extend the layout.

## Editing text

All content lives in `index.html`. Open it in any editor and change the text between the tags —
nothing needs compiling. Save, re-upload to GitHub, done.
